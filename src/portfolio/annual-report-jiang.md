## Overview

Based on a software test engineer's annual work, this project creates an annual presentation. It explores using Slidev, outlines, datasets, and AI agents to generate presentation documents intelligently. Unlike image-based PDFs generated by some AI tools, this project produces precise data visualizations with consistent layouts and standards. All charts and content remain editable, costs stay low, and WPS or similar PDF-to-PPT workflows can generate PowerPoint components that are easy to reuse in other projects.

## Features

Slidev provides core presentation features and animations; see the live project for the full experience.

## Implementation

Slidev framework + custom Vue components + AI skill styling guidelines

## Retrospective

The layout and content style are well standardized, and outlines can generally generate new pages in the intended visual style. Individual components still require iterative adjustment, so there is an opportunity to explore reusable patterns and foundational template components for technical presentations while keeping the visual system controllable.
