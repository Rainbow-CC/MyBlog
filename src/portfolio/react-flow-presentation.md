## 项目定位

react-flow + skill 形式，指引AI生成指定风格的图片，用来写技术文档。

## 功能展示

每个图一个tab. 包含png裁剪导出、svg裁剪导出等模式，可导出裁剪后的图片，直接插入到文档即可。
